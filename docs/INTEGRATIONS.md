# Connected features

Contact and scheduling use writevarun2006@gmail.com. The form opens a draft in the visitor's email app; it does not send email automatically.

Apple Music links to https://music.apple.com/profile/varun/129 as requested. It is a profile link, not a live listening-history feed.

For the optional real visitor ordinal, set UPSTASH_REDIS_REST_URL and UPSTASH_REDIS_REST_TOKEN in Vercel and redeploy. Keep secrets out of source. The server atomically counts a random browser ID once. This measures browsers, not verified people; clearing storage creates a new ID. The counter begins at one, never at a copied number. Without configuration or if the service fails, the quote panel keeps its welcome message.

Vercel serves api/integrations.js separately from dist. Local static preview cannot run the API.
